✅ 95.52% Test Accuracy · OpenForensics Dataset · Major B.Tech Project

Movie Recommendation System
Content-based and collaborative filtering recommendation engine using cosine similarity. Built with Python, Pandas, Scikit-learn, and NLTK to deliver personalized movie suggestions.

Kidney Stone Detection
Medical image classification system using XResNet50 to detect kidney stones from CT scans, with confusion matrix and ROC curve analysis for robust diagnostic evaluation.

IoT-based system using NodeMCU and DS18B20 sensors for real-time aquarium temperature monitoring with automated regulation and manual mobile control via Blynk app. Published at ICECMSN 2025.
